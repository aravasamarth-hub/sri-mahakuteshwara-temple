# Mahakaleshwar Temple, Badami

## Product
Frontend-only bilingual temple website with English-first content, Kannada toggle, React-state day/night theme, uploaded devotional audio control, responsive navigation, and static inquiry forms. Its reusable Royal Chalukya ornament system (reference: TTD-style heritage mockup) is a set of vector masks in `frontend/public/ornaments/` generated by `frontend/scripts/gen_ornaments.py`: `flank-left.svg` / `flank-right.svg` (dense floral scrollwork, tiling vertically), `corner-mandala.svg` (used as half-mandalas peeking in from the mid edges on desktop, centred on mobile sections), `lotus-border.svg` (base border) and `temple-skyline.svg` (gopuram line art at the foot of every page hero). They are painted by a shared `::before` layer on `.section-pad`, `.page-hero`, `.hero-section` and `.temple-footer` via CSS `mask-image`; colour/opacity come from `--ornament-ink` / `--ornament-opacity` (day #BF8A3C at 28% on #FDF7E8, night #C9A227 at 24% on #0D0B08, footer gold 22%) and scale from `--orn-flank`, `--orn-ms`, `--orn-lotus`, `--orn-sky` (reduced under 760px). Palette follows the reference: day #FDF7E8/#E8D4A3/#D4AF37/#B46A2C/#5C3A21, night #0D0B08/#1A140B/#C9A227/#8B6F3D/#EAD8A8. Note: `mask-position` values must be 2- or 4-value (`left X top 50%`), never the legacy 3-value form.

## Key flows
- Visitors can browse Home, About, Timings, Poojas, Donations, Rooms, Marriage Halls, and Contact routes.
- Pooja, donation, room, and hall actions open validated modal forms with confirmation states. No submissions leave the browser.
- Contact form validates name, phone, and message, then shows a confirmation state.
- Theme, language, and audio playback are held in React state for the current session only; the uploaded devotional MP3 starts muted and can be played or paused from the shared control.

## Data
Static in `frontend/src/lib/temple.ts`: four required poojas without displayed pricing, four donation categories, two halls, temple copy, and five supplied image URLs. Backend and database are intentionally not used by the frontend MVP.

## Auth
None. No credentials or gated areas.
